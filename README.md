## 🏛️ תיאור המערכת והשקופיות

הלוח הראשי (`index.html`) מציג:
1. **סרגל עליון (Header):** שם בית הכנסת, תאריך עברי ולועזי מדויקים, פרשת השבוע הנוכחית ושעון דיגיטלי חי.
2. **עמודת זמני היום בהלכה (אופק ירושלים):** חישוב אסטרונומי אוטומטי יומי (עלות השחר, נץ החמה, סוף זמן ק"ש ותפילה, חצות, מנחה גדולה/קטנה, פלג המנחה, שקיעה וצאת הכוכבים) + זמני כניסת ויציאת שבת.
3. **אזור שקופיות מתחלפות (Carousel):**
   - **שקופית 1 — זמני תפילות לימות החול:** שחרית, מנחה, ערבית ושיעורי תורה קבועים.
   - **שקופית 2 — לוח זמנים לשבת קודש:** זמני מנחה בערב שבת, קבלת שבת, שחרית, שיעורים, תהילים לילדים, מנחה א'/ב', סעודה שלישית, ערבית במוצ"ש ואבות ובנים.
   - **שקופית 3 — מודעת כולל בוקר:** פרטי הלימוד והשיעורים בכולל.
   - **שקופית 4 — לוח "לעילוי נשמת" (נפטרים ואזכרות):** הצגת שמות הנפטרים של החודש העברי הנוכחי (עם הדגשת השבוע הקרוב) בחלוקה לעמודים מתחלפים.
   - **שקופית 5 — תרומות ונדרים:** פרטי העברה בנקאית וקוד QR לתרומה מהירה ב-Bit.
   - **שקופיות נוספות (מותאמות אישית):** הודעות אבל/שמחה, מודעות חגים (ראש השנה, יום כיפור, סוכות וכו') ומודעות מעוצבות שנוספות דרך מערכת הניהול.
4. **סרגל הודעות רצות (Ticker) בתחתית המסך:** הודעות קהילתיות, ברכות ואיחולים.

ישנן שתי דרכים לבצע עדכונים שוטפים במערכת:

### דרך א׳ (מומלצת לשוטף): עדכון דרך ממשק הניהול לגבאי (ללא צורך בקוד או ב-Deploy)

1. **עדכון שבועי של זמני שבת וזמני ימות החול:**
   - מיד בכניסה לממשק הניהול נפתחת הלשונית הראשית: **`✨ זמני שבת וימות החול (עדכון שבועי לגבאי)`**.
   - **בחלק העליון:** מופיעה טבלת **זמני תפילות שבת קודש** (שקופית 2) — ניתן לשנות את שם הפרשה/הכותרת ואת השעות בשדות הצהובים המודגשים.
   - **בחלק התחתון באותו עמוד:** מופיעה טבלת **זמני תפילות לימות החול** (שקופית 1) — ניתן לערוך את השעות של שחרית, מנחה, ערבית ושיעורי התורה, וכן להוסיף או למחוק שורות.
   - לחיצה על הכפתור הירוק בתחתית המסך **`💾 שמור ועדכן זמני שבת והשבוע בלוח`** שומרת את השינויים בענן (Firestore תחת `synagogue/mainConfig`) ומעדכנת **באופן מיידי** את המסך בבית הכנסת (ללא צורך ברענון המסך).

2. **ניהול מודעות, שקופיות, נפטרים והודעות רצות:**
   - בלשונית **`🖼️ ניהול שקופיות ומודעות`**: ניתן להפעיל/לכבות שקופיות, לשנות את סדר הופעתן או משך ההצגה שלהן, ולהוסיף מודעות מיוחדות (כגון מודעות אבל, מזל טוב או זמני חגים).
   - בלשונית **`🕯️ רשימת נפטרים`**: ניתן להוסיף, לערוך או לחפש שמות נפטרים ותאריכי פטירה עבריים.
   - בלשונית **`📢 הודעות רצות וכללי`**: ניתן לערוך את ההודעות הרצות בתחתית המסך ואת פרטי התרומות.

   - ב-`index.html` קיים אובייקט גיבוי (`FALLBACK_CONFIG`) למקרה שאין חיבור רשת. מומלץ לשמור אותו מסונכרן עם `prayers_config.js`.
3. **⚠️ חשוב מאוד — קידום מספר הגרסה (`configVersion`):**
   - כאשר מעדכנים זמנים דרך הקוד ב-`prayers_config.js` ורוצים שהשינוי בקובץ ידרוס הגדרות ישנות שנשמרו ב-`localStorage` של הדפדפן, יש להגדיל את הערך של `configVersion` (למשל ל-Timestamp נוכחי) גם ב-`prayers_config.js` וגם ב-`index.html`:
     ```javascript
     configVersion: 1792130300000, // עדכן למספר גבוה יותר בכל שינוי קוד
     ```
   - אם כבר נשמרו נתונים בענן (Firestore) ורוצים שהמסך ימשוך את ברירת המחדל החדשה מהקוד, ניתן ללחוץ בממשק הניהול (`admin.html`) על כפתור **"🔄 איפוס לברירת מחדל"** או לשמור מחדש דרך `admin.html`.

## 🚀 איך מבצעים פריסה לשרת (Deploy)?

הפרויקט מתארח ב-**Firebase Hosting** תחת הפרויקט `yefenof-b90a0`.

### דרישות קדם
- מותקן `Node.js` ו-`npm` (כדי להריץ `npx`).
- מחובר לחשבון Google בעל הרשאות לפרויקט `yefenof-b90a0` (באמצעות `npx -y firebase-tools@latest login`).

### 1. פריסת האתר (Hosting — הפקודה השוטפת)
מתוך תיקיית הפרויקט (`/Users/natip2/Documents/IdeaProject`), הרץ בטרמינל:

```bash
npx -y firebase-tools@latest deploy --only hosting
```

פקודה זו מעלה את כל קובצי האתר (`index.html`, `admin.html`, `prayers_config.js` וכו') ומעדכנת מיד את האתר החי בכתובת `https://yefenof-b90a0.web.app`.

### 2. פריסה מלאה (כולל חוקי Firestore)
אם בוצע שינוי גם בקובץ [`firestore.rules`](file:///Users/natip2/Documents/IdeaProject/firestore.rules), הרץ:

```bash
npx -y firebase-tools@latest deploy
```

### 3. בדיקת תקינות לפני פריסה (אופציונלי)
לבדיקה מהירה שאין שגיאות תחביר (Syntax Errors) בקובץ ההגדרות לפני העלאה לשרת:

```bash
node -c prayers_config.js
```
