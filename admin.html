💾 גיבוי והורדת קובץ קונפיגורציה

ניתן להוריד את קובץ ה-prayers_config.js המעודכן עם כל השינויים (תפילות + כל הנפטרים) ולהחליפו בתיקיית הפרויקט.

☁️ הגדרות חיבור ל-Firebase Cloud Firestore

חיבור ל-Firebase מאפשר לעדכן את לוח בית הכנסת בזמן אמת מכל מחשב או סמארטפון!

📖 מדריך מהיר להגדרת פרויקט Firebase בחינם (2 דקות)

  1. היכנס לאתר Firebase Console עם חשבון גוגל ולחץ על "Add Project".
  2. תן שם לפרויקט (למשל: synagogue-display) ולחץ המשך.
  3. בתפריט השמאלי, לחץ על Build -> Firestore Database ולחץ על Create Database (בחר מיקום eur3 או nam5 ומצב Start in test mode).
  4. בעמוד הראשי של הפרויקט, לחץ על סמל ה-Web </> כדי לרשום אפליקציה, והעתק את אובייקט ה-firebaseConfig לשדות למעלה.
  5. לחץ על "שמור הגדרות ענן" ולאחר מכן "העלה את כל הנתונים לענן" — ומאותו רגע כל שינוי יסונכרן למסך בית הכנסת מיידית!
